# Legacy source inputs

These files were extracted without modification from SageMath's
`elliptic_curves-0.8.1.tar.bz2` source archive.

- SHA-256: `5fba5470d9d91f06282ed5edfc45bf0ea1c5f7c8d4837c46234b17be1481fd50`
- Sage package metadata: `build/pkgs/elliptic_curves/checksums.ini`

`common/allcurves.00000-09999` is the input for the mini Cremona SQLite
database and for ranks 0, 1, and 2.  The files under `ellcurves/` are appended
to the corresponding rank-grouped output by `generate.py`.

See the repository-level `DATA_LICENSES.md` before redistributing these data.
